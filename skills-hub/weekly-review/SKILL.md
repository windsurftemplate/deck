# Weekly review

1. List issues closed this week, grouped by goal. Use the tracker, not memory.
2. For each active goal, state progress against its milestones and whether it is on track.
3. List commitments the owner made (from memory and chats) that slipped, with who is waiting.
4. Note anything waiting for the owner's approval for more than two days.
5. Propose the top three priorities for next week, each tied to a goal.

## Output
A short note with five headings: Done, Goals, Slipped, Waiting on you, Next week. Under 250 words.
