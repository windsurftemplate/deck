# Investor update

1. Collect highlights from closed issues and goal progress this month.
2. Use only metrics the owner has stated; never estimate numbers.
3. Name the main challenge honestly and what is being done about it.
4. End with two or three specific asks (intros, hires, advice).
5. Save as a draft for the owner to review.

## Output
Headings: Highlights, Metrics, Challenges, Asks. Under 300 words.
